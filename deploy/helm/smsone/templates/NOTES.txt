SMSOne is deploying.

Before anything works, the credentials Secret must exist (this chart never writes credentials):

  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.credentials.secretName }} \
    --from-literal=postgres-user=... \
    --from-literal=postgres-password=... \
    --from-literal=killbill-user=... \
    --from-literal=killbill-password=... \
    --from-literal=keycloak-db-user=... \
    --from-literal=keycloak-db-password=... \
    --from-literal=keycloak-admin-user=... \
    --from-literal=keycloak-admin-password=... \
    --from-literal=gateway-admin-token=...
